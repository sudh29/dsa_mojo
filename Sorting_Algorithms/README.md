# Sorting Algorithms

This directory contains implementations of fundamental sorting algorithms in Mojo.

---

| Algorithm | File | Time Complexity (Avg) | Space Complexity |
|-----------|------|-----------------------|------------------|
| Bubble Sort | [bubbleSort.mojo](bubbleSort.mojo) | $O(N^2)$ | $O(1)$ |
| Heap Sort | [heapSort.mojo](heapSort.mojo) | $O(N \log N)$ | $O(1)$ |
| Insertion Sort | [insertionSort.mojo](insertionSort.mojo) | $O(N^2)$ | $O(1)$ |
| Merge Sort | [mergeSort.mojo](mergeSort.mojo) | $O(N \log N)$ | $O(N)$ |
| Quick Sort | [quickSort.mojo](quickSort.mojo) | $O(N \log N)$ | $O(\log N)$ |
| Selection Sort | [selectionSort.mojo](selectionSort.mojo) | $O(N^2)$ | $O(1)$ |
