# Basic Codes and Language Fundamentals

This directory contains introductory exercises, fundamental algorithms, and utility scripts written in Mojo.

---

| File | Description |
|------|-------------|
| [1.mojo](1.mojo) | Basic syntax, types, and arithmetic operations |
| [2.mojo](2.mojo) | Collections, functions, and recursive Fibonacci |
| [3.mojo](3.mojo) | Pseudo-random number generation and 2D random walk simulation |
| [4.mojo](4.mojo) | Struct definitions, methods, and math functions |
| [5.mojo](5.mojo) | Collection traversal and test verification |
| [anagrams.mojo](anagrams.mojo) | Anagram verification using character sorting |
| [CountOnes.mojo](CountOnes.mojo) | Counting set bits from 0 to N using bitwise & DP techniques |
| [file.mojo](file.mojo) | Memory buffer / file simulation operations (write, seek, read) |
| [gridPath.mojo](gridPath.mojo) | Unique grid paths with obstacles using DP |
| [hello.mojo](hello.mojo) | Hello world and control flow basics |
| [patternCount.mojo](patternCount.mojo) | Overlapping and non-overlapping pattern matching |
| [primeOrNot.mojo](primeOrNot.mojo) | Prime number testing using trial division |
| [swap2no.mojo](swap2no.mojo) | Number swapping using XOR, arithmetic, and temporary variables |
| [systemDetails.mojo](systemDetails.mojo) | System architecture queries (word size) and digit sum |
